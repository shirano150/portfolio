# 👹 마계촌 온라인

![마계촌 온라인](../assets/images/projects/makaimura-online.jpg){ .cover }

!!! note ""
    PC MORPG. 한국과 중국 서비스 런칭부터 라이브 종료까지 서버 팀장으로 참여했습니다.

## 개요

| 항목 | 내용 |
|---|---|
| 회사 | 넷마블 몬스터 |
| 기간 | 2012.02 – 2014.12 |
| 장르 / 플랫폼 | MORPG / PC |
| 직책 | 서버 팀장 |
| 참여 범위 | 2차 CBT → 한국/중국 서비스 오픈 → 라이브 운영 → 서비스 종료 |
| 아키텍처 유형 | MMO형 |

## 서비스 인프라 구성

| 계층 | 구성 |
|---|---|
| 클라이언트 | PC (한국, 중국) |
| 게임 서버 | C++, Boost, ProudNet 기반 실시간 서버 |
| 데이터 | MS-SQL |
| 모니터링 · 운영 도구 | MFC 기반 실시간 지표(트래픽, 세션, 자원 사용량) 수집·시각화, 알림, 로그 분석 |

- 대규모 동시 접속 환경에서의 안정적인 처리 구조와 데이터 무결성을 위한 트랜잭션 처리 설계
- 병목 구간 분석과 레거시 코드 리팩터링으로 서버 성능 최적화

## 서비스 오픈에서 한 일

- 서버 팀장으로 2차 CBT부터 한국·중국 서비스 오픈까지 개발 일정과 기능별 우선순위 관리
- 운영팀·QA팀이 직접 쓸 수 있는 모니터링과 알림, 로그 분석 도구 제공
- 오픈 후 라이브 운영과 서비스 종료까지 대응

## 담당 업무

- 게임 서버 설계 및 구현
- 게임 콘텐츠 개발 및 시스템 구현
- 팀 개발 일정 관리
- 서비스 운영을 위한 MFC 기반의 백오피스 개발
- 실시간 지표(트래픽, 세션, 자원 사용량) 수집 및 시각화 기능 구현
- 운영/QA 팀에서 활용할 수 있도록 알림, 로그 분석 기능 구축

## 세부 내용

### 핵심 게임 시스템 서버 로직 개발

- 퀘스트, 업적, 개인 거래, 결제, 칭호 등 핵심 시스템 개발
- 대규모 동시 접속 환경에서의 안정적인 처리 구조 설계
- 데이터 무결성 보장을 위한 검증 로직 및 트랜잭션 처리 개선

### 운영용 모니터링 툴 개발 (MFC)

- 실시간 지표(트래픽, 세션, 자원 사용량) 수집 및 시각화
- 운영팀과 QA팀이 활용할 수 있는 알림, 로그 분석 기능 구축

### 레거시 코드 개선 및 안정화

- 모듈 단위 분리 및 유지보수성이 낮던 코드 리팩터링
- 병목 구간 분석 및 서버 성능 최적화

### 팀 운영

- 팀 개발 일정 관리 및 기능별 우선순위 조정
