# 🎮 서강훈 포트폴리오

!!! quote ""
    **안녕하세요, 게임 서비스 인프라와 서버 아키텍처를 설계해 온 서강훈입니다.**
    15년 동안 MMO, 세션·매치, 모바일 RPG 등 다양한 장르의 온라인 게임 서비스를 프로토타입부터 서비스 오픈, 라이브 운영까지 경험했습니다. AWS 기반 인프라 구축과 배포 자동화, 모니터링까지 직접 설계하며 안정적으로 운영되는 서비스를 만드는 데 집중해 왔습니다.

## 이런 일을 해 왔습니다

- **서비스 오픈 준비와 일정 관리**: 팀장·파트장으로 서버 개발 일정과 우선순위를 관리하고, CBT·얼리 액세스·지역별 오픈과 외부 행사에 대응
- **서비스 아키텍처 설계**: MMO형, 세션·매치형, 모바일 RPG등 장르 특성과 트래픽 패턴에 맞는 서버·DB·네트워크 구조 설계와 대규모 트래픽 대응 구조 개선
- **유관부서 협업과 문서화**: Wiki를 구축해 유관 부서 협업 체계를 정립하고, 운영·QA가 직접 쓰는 모니터링·로그 분석·백오피스 도구 제공
- **표준화와 자동화**: CloudFormation 기반 IaC, Jenkins·Ansible·AWX 배포 자동화, Prometheus·Grafana·Sentry 모니터링과 로그 파이프라인을 여러 타이틀에 반복 구축

## 대표 프로젝트

- [트랜스포머 멀티 쇼크](projects/transformers-multi-shock.md): 모바일 RPG, AWS 인프라·CI/CD·모니터링 구축과 일본 서비스 오픈 (서버 팀장, 2024–2025)
- [Dubium](projects/dubium.md): 세션·매치형 PC 게임, CloudFormation IaC와 GameLift 기반 인프라, Steam 얼리 액세스 오픈 (서버 팀장, 2022–2023)
- [Relic Keepers](projects/relic-keepers.md): 세션·매치형 모바일 게임, 실시간 통신·로비 서버 구조 설계와 서비스 오픈 (서버 파트장, 2020–2022)
- [마블 퓨처 파이트](projects/marvel-future-fight.md): 글로벌 모바일 RPG, 대규모 트래픽 대응 구조 개선과 글로벌 런칭 (2014–2016)
